# DoceCapricho

## Sobre o site

Escolhi criar um site de uma doceria fictícia, onde o
usuário pode montar seu próprio doce de acordo com
suas preferências.

O site possui três opções de doces: donut, cupcake
e cookie. É possível escolher a massa, o recheio,
a cobertura, a decoração e a quantidade.

O preço muda conforme as opções escolhidas.

## Linguagens utilizadas

- HTML
- CSS
- JavaScript

## Funcionamento

O formulário calcula o valor dos doces e dos adicionais.

Caso algum campo obrigatório não seja preenchido ou a quantidade seja inválida, aparece uma mensagem de erro.

Quando o pedido é aceito, ele aparece na lista de criações e no histórico de pedidos.

O site também se adapta a telas menores.

## Regras do formulário

- A quantidade deve ser de 1 a 100 doces.
- Não são aceitos números negativos ou decimais.
- Todos os campos são obrigatórios, menos as observações.

## Como abrir o site

Abrir o arquivo index.html pelo navegador.
